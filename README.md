## The word

**doomscrolling**

The internet's signature behaviour is not searching, posting, or shopping — it is the thumb that keeps scrolling long after the brain has checked out. One word, funny and fitting at once, no explanation needed.

## How it works

`main.ts` validates the word (a single token, 1–30 characters, per the bounty gate) and writes it to `/output/entry.txt`, then reads it back to prove the bytes landed intact.

Run it:

```sh
npx tsx main.ts
# or, with a custom output dir:
MAKEFUN_OUTPUT_DIR=out npx tsx main.ts
```
